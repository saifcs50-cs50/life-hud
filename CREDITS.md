# Credits

Nothing in this repository is copied from another project's assets. The icons, 3D scenes and ambient sounds are
generated in code (lucide icons, three.js primitives, Web Audio oscillators). The favicon is a small SVG drawn for
this project.

## Fonts

Loaded at runtime from Google Fonts by `index.html`; the font files are not stored in this repository.

- [Rajdhani](https://fonts.google.com/specimen/Rajdhani), SIL Open Font License 1.1
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/), SIL Open Font License 1.1

## Libraries

Installed from npm (see `package.json` and `package-lock.json` for exact versions and each package's own licence):
React, React Router, Vite, Tailwind CSS, three.js, @react-three/fiber, @react-three/drei, Recharts, Framer Motion,
Zustand, Dexie, lucide-react (icons, ISC), clsx, TypeScript and Oxlint.

The F1-style wording in the interface (pit stop, slipstream, black flag, grid walk, team radio and so on) is generic
motor-racing vocabulary used as a visual theme. This project is not affiliated with or endorsed by Formula 1 or any
racing team, and it uses no team, driver or series names or logos.
